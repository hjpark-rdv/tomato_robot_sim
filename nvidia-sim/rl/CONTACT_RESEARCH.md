# 고리로 꼭지를 거는 접촉 동작: 조사와 구현 판단

조사일: 2026-09-19. 2024–2026년 논문과 저자 공개 자료, NVIDIA PhysX 문서,
MIT 로봇 조작 강의를 확인했다. 아래는 이 작업과 직접 관련된 선별 조사이며,
문헌 전체를 망라한 체계적 문헌고찰이나 논문 알고리즘의 완전한 재현은 아니다.

## 현재 문제를 어떻게 정의할 것인가

목표는 TCP가 특정 좌표에 도착하는 것이 아니라 **열매를 고리 안에 넣고,
과육을 밀어 떨어뜨리지 않으면서 고리의 안쪽 면을 꼭지에 접촉시켜 분리하는 것**이다.
OMPL의 장애물 회피와 Cartesian 경로는 접근 단계에 유용하다. 마지막 단계는
의도한 접촉과 피해야 할 접촉을 구분하고 물리 결과를 평가해야 한다.

기존 GUI의 `harvest_planner.py`에서 확인한 내용:

- `make_tip_local_harvest_motion`: 전진 40mm, 전진 20mm + 상승 20mm,
  상승 20mm, 후퇴 50mm, 대기 후 후퇴 10mm의 기본값과 사용자 지정 단계.
- `make_harvest_geometry`: 실제 gripper +X는 로봇 쪽, +Y는 아래쪽인 수평 고리.
- `PICK_READY`: SRDF에서 읽어 시뮬레이션에도 적용.

GUI의 고정 이동량을 지름 약 20–25mm의 현재 원본 열매에 그대로 적용하기보다는,
열매 중심·꼭지·인접 열매를 기준으로 높이와 방향을 탐색한다.
고리 중심과 `tomato_gripper_tip`은 다른 프레임이므로 같은 좌표로 취급하지 않는다.

## 구현 방향

1. 원본 house, 줄기와 열매 11개, Ver.6 고리, 실제 관절 구동을 유지한다.
2. 초기 팔은 ROS `PICK_READY`, 장착면은 송이 평균 높이보다 40cm 아래다.
3. URDF 기반 FK를 현재 PhysX 자세와 대조하고, 관절/리프트 범위 내에서 IK를 푼다.
4. 아래 진입 → 열매 삽입 → 꼭지 높이로 상승 → 바깥쪽 당기기의 동작을
   토마토 기준 좌표로 생성한다. 후보마다 방향·깊이·상승량·기울기를 바꾼다.
5. 기하학적 간격 점수는 후보 선별에만 사용한다. 성공은 실제 물리 rollout으로 판정한다.
6. 목표 과육 삽입 이력, 고리–목표 꼭지 접촉, native joint break와 이웃 열매 상태를 기록한다.

원본 파손값 3N / 0.08N·m은 유지한다. 목표에 가까워졌다고 joint를 삭제하거나,
실행 중 로봇/열매를 목표 위치로 순간 이동시켜 성공시키지 않는다.

## 모델의 한계

현재 꼭지는 캡슐 접촉 근사와 파손 가능한 고정 조인트다. 분리 전의 굽힘,
조직의 손상 누적, 과육 멍, 실제 열매 회수는 별도 문제다. 따라서 시뮬레이션에서
동작을 얻더라도 실제 작물 수확 성능이 검증된 것은 아니다. 시각적인 잎 형상과
접촉 강성도 구분해야 한다. 시뮬레이터 상태를 직접 사용하는 이번 작업에 비전 오차는 없다.

이후에는 성공 시연 모방 → 위치·마찰·파손값 무작위화 → 기본 동작 위의 작은 residual
제어 학습 순서가 적합하다. 실제 로봇에서는 TCP 보정, 힘 추정/센서, 허용 힘과 속도,
줄기의 변형을 먼저 맞춰야 한다.
