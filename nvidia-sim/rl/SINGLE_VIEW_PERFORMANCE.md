## 수정 내용

- 단일 환경은 원본 하우스·로봇·식물을 직접 표시한다. 다중 환경은 기존 표시용 복제를 유지한다.
- 매 물리 스텝의 USD 화면 변환 쓰기를 화면 갱신 시점으로 옮겼다. 물리 텐서와 접촉 정보는
  기존 주기로 읽는다. 리셋은 기존의 명시적 USD 동기화를 유지하며 종료 시 설정을 복구한다.
- 식물 시각 메시의 고정 skin weight 계산을 희소 행렬로 캐시하고 USD 변경 통지를 묶는다.
  충돌체·힘·물성·물리 상태를 보정하지 않는다.
- 화면 시간에 남아 있던 960Hz 고정값과 16스텝 갱신 제한을 제거했다.
- `--view-fps`는 최대 갱신율이다. 렌더링 비용을 측정해 표시 비용이 실행을 과도하게
  차지하지 않도록 갱신 간격을 조절한다. 물리 스텝을 생략하거나 시간을 변경하지 않는다.
- 최종 시험의 상태 갱신은 104초에 225회(약 2.16회/초), 화면 처리 총 19.50초였다.
  `display_timings`를 진행 로그와 summary에 추가했다.

## 실행

기존 명령을 그대로 사용할 수 있다. 아래는 49번만 실행하고 창을 유지한다.

```bash
DISPLAY=:0 ./nvidia-sim/run_gpu_candidate_dataset.sh \
  --physics-preset contact120 --trajectory-mode staged6d \
  --num-envs 1 --candidates 64 --candidate-indices 49 \
  --planning-workers 1 --schedule batch --view-grid --view-fps 10 --keep-open
```

화면 없이 실행할 때는 `--view-grid --view-fps 10 --keep-open`을 빼면 된다.
물리 처리만 약 73초이므로 이번 화면 최적화만으로 실시간 실행까지 되지는 않는다.
