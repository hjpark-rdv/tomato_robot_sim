# 잡는 간격·높이 변경으로 벨트 단계 분리 확인

> 최신 사용자 패턴과 결과는 문서 마지막 **열린 채 벨트 가동 → 닫기 → 완전 열기 → 다시 닫기** 절을 따른다. 닫기 중 분리 자체는 실패가 아니다.

2026-10-10. 기준 `76479ee`, 브랜치 `codex/s300-harvest-isaac-20261009`.
앞선 [열매–꼭지 탄성 연결 시험](FRUIT_ATTACHMENT_TEST_KO.md)의 후속이다.
같은 탄성 연결 시험안에서 닫기 중 조기 파단과 상판–8번 겹침을 줄이기 위해
잡는 간격과 높이만 변경했다. 실물 파단 특성이 보정된 모델은 아니다.

**40mm 간격, 기존 잡기 기준점보다10mm 낮게 접근하면60/120Hz 모두 닫기 중
조기 파단 없이 벨트 단계에서10번이 분리되고 개방·후퇴까지 완료됐다.**
60Hz는30.5초 동작을38.395초에 처리했다(0.794배속, 초기화·계획·사후 검사 제외).
벨트 정지 대조군은60/120Hz 모두 분리0이었다. 한 장면에서의 개선이며,
모든 시간 간격에서 결과가 일치하는 수확 모델을 완성한 것은 아니다.

240Hz의40mm 설정은 닫기 중 조기 파단이 남았다. 간격을42mm로 넓히면
60/240Hz 분리0,120Hz는 벨트 중 분리 후 바닥 겹침0.513mm로 중단됐다.
그 사이41mm에서도240Hz 벨트 분리/60·120Hz 분리0으로 차이가 남았다.
이 추가 비교 뒤에는 파단값을 조절하거나 무한히 위치를 미세 조정하지 않았다.
추가 개발은 힘을 제한하는 잡기 제어와 연결부 반력·실물 파단 특성 검증이 필요하다.

최종60Hz GUI는 현재 송이 과실–그리퍼도 **원래0.5mm 기준**으로 재시험했다.
전체 완료,10번17.833333초 벨트 단계 분리, 최대 겹침0.191659mm,
처리38.586초(0.790배속). 실제 자기충돌 검사도 통과했다.
headless의 명령/시간/단계/실제 robot q/모든 바디 pose/벨트 속도와 bit-exact였다.
실제 진입 구간의 tool +Y pitch 최대는60Hz 0.051°/120Hz 0.043°,
높이 변동 범위는 각각0.256/0.210mm였다(`entry_geometry.json`).
60·120Hz의40mm 벨트off 대조는 동일한 명령/시간 및 벨트 이전 실제 상태에서 분리0이다.

총 headless15회와 GUI1회를 새 실행했다. 초기 높이의40/36mm는 상판–8번 겹침으로
중단됐다. 높이−20mm는 완료했지만 분리0,−12mm/120Hz는 벨트 단계 분리와 완료였다.
이 결과들을 모두 비교표에 보존한다. 처리 시간은 물리 루프이며 앱 시작·모델 준비·
계획·사후 검사·저장·영상 렌더 시간은 별도다. 새 병렬 환경 성능은 측정하지 않았다.

관련 자동 테스트89개 PASS. 기본 명령 유지, 높이/간격 옵션, 실제 입력 불변성,
범위 거부, 연결부 메타데이터 일치, 물리·접촉·자기충돌·live 표시 회귀를 포함한다.

## 변경 내용

- `--grasp-gap-mm`: 닫기·벨트 단계의 기계적 jaw 명령 간격. 기본28mm 유지,
  기존 기구 이동범위28~96mm 안에서 선택한다. 충돌 margin이나 과실 압축 허용치가 아니다.
- `--grasp-height-offset-mm`: 저장된 잡기 기준점 대비 world Z 이동량. 기본0,
  ±50mm 범위의 opt-in이다. 식물 위치를 바꾸지 않고 실제 로봇 IK 경유점을 다시 계산한다.
- 원래 대기 자세를 유지하고 준비 이동 중 높이를 조정한다. 그리퍼 자세는 수평이며
  마지막100mm 진입은 일정 높이다. 높이 변경 시 준비 구간의 이동 자체는 완전 수평이 아니다.
- 기존 계획/실제 자기충돌 검사, native PhysX 실행, 매 물리 스텝 상태·접촉 기록,
  기존 분석/HTML/영상 생성기를 재사용한다. 기존 모드의 기본 동작은 유지한다.
- live 실행기에 `S300_GRASP_GAP_MM`, `S300_GRASP_HEIGHT_OFFSET_MM`을 연결했다.

## 고정한 조건

현재 송이10개 과실의 수동 탄성 연결/3N/0.008Nm를 그대로 사용한다.
이 낮은 파단 토크는 앞선 실험의 가설이며 이번에 추가로 낮추지 않았다.
기존 별도5mm 벨트 접촉면 시험안을 사용한다. 원래 CAD/V6 검증이 아니다.
full612DOF 식물, 충돌체, 질량, 마찰, 강성·감쇠, actuator, CCD를 바꾸지 않았다.
접촉 기준도 이전의 현 송이 과실–그리퍼1mm, 나머지 활성 쌍/초기 상태0.5mm를 유지한다.

수평 진입 → 닫기6초 → 벨트2초(가감속0.5초) → 개방 → 후퇴 → 복귀,
전체30.5초다. 벨트 입력은 기존 speed0.05/infeed0.05m/s이며 실제 표면 속도는
왼쪽−0.10m/s/오른쪽0이다. 양쪽 대향 회전으로 잘못 해석하지 않는다.
TGS64/4, CPU2스레드. Hz 비교 외의 solver 조건은 같다.

잡기 기준점은 기존10·11번 과실 중간을 사용한다. 이번에 관찰한 분리는10번이다.
명목 target인11번까지 분리했다고 세지 않는다. 40mm는 기계적 명령 간격이며
5mm 접촉면 두 개를 고려하면 명목 벨트면 간격은30mm다. 실제 접촉 중 간격은
추종 오차와 하중에 따라 달라지며 `states.npz`의 실제 jaw 상태로 따로 측정한다.

`assembly_elastic` 생성 시 manifest의 `target` 복사본에도 실제 파단값을 기록하도록
수정했다. 이전 `plant.fruits`와 native USD는 이미 올바른 값이었다.
재생성 USD 해시는 앞선 `assembly_elastic_weak_v2`와 같으며 이 수정은 물리 변경이 아니다.
기존 assembly/실험 파일은 덮어쓰지 않았다.

## 최신 패턴: 열린 채 벨트 가동 → 닫기 → 완전 열기 → 다시 닫기

2026-10-10 후속 사용자 정정. **닫는 중 분리 자체를 실패로 분류하지 않는다.**
위의 40mm 시험은 벨트를 끈 채 닫고 이후 벨트를 켰던 별도 조건이다.
현재 사용자는 닫기·열기 동안 벨트를 계속 회전시키도록 지정했다.
완전히 닫기 전에 분리되거나 다시 여는 도중 분리되는 것을 허용한다.

기존 `plan_motion`/native 실행기/실제 상태 기록/분석/뷰어에 opt-in
`--harvest-profile belt_open_close_cycle`과 live `cycle` 선택만 추가했다.
기존 `legacy`/`belt_spin_release` 명령을 유지한다.

- 수평 열린 진입96mm → 열린 상태로 벨트 시작1초 → 28mm까지 닫기6초
  → 벨트를 유지한 채96mm로 열기1초 → 열린 상태0.5초 → 다시28mm로 닫기6초.
- 이후2초 더 돌린 뒤 벨트 정지, 개방·후퇴·복귀. 전체39초.
- 벨트는 두 번의 닫기와 사이의 열기에서 끊기지 않는다. 시작/끝에만0.5초 가감속.
  양쪽 회전 조건은 표면속도 왼쪽−0.05/오른쪽+0.05m/s, 공통 이송0이다.
- 재닫기 전에 실제 jaw 간격이96±0.5mm인지 확인한다. 명령값으로 대체하지 않는다.
  미도달이면 `cycle_reopen_not_reached`로 정지한다. 이번 모든 시험은 약95.994mm로 통과.
- 28mm는 원래 최소 기계적 명령 간격이다.5mm 벨트 접촉면 시험안의 명목 면간격은18mm.
  과실 접촉 중 실제 간격은 명령보다 넓을 수 있으며 실제값을 별도로 저장한다.

같은 full612DOF/5mm 접촉면/수동 탄성3N·0.008Nm 시험안을 재사용했다.
높이−10mm, TGS64/4, CCD, CPU2, 질량·강성·마찰·actuator 모두 유지했다.
이번에는 **모든 활성 접촉을 원래0.5mm 기준**으로 검사했다. 파단값이나 허용치를
상향/하향 조정해 새 결과를 만들지 않았다. 별도 사용자 V6 파일도 수정하지 않았다.

### native 접촉 기록과 계산 후 형상 검사
