# 레일 수확 준비 경로의 제한된 대체 IK 시험

2026-10-11. 이 결과는 실제 수확 성공이 아니라 동일 v6 농장 자산에서의 IK와 로봇 자체 충돌 검사다. 수평 진입, 송이 방향 yaw, 2 mm FCL 여유, 전체 120 Hz 경로 검사를 유지했다. 기본 명령 배열은 기존 golden SHA와 동일하다.

| 범위 | 실제 질의 | 전체 자체 충돌 검사 통과 | 제한된 계획 실패 |
|---|---:|---:|---:|
| 원래 46개 적격 송이, Cartesian 준비 | 91 | 21 | 자체 충돌 38 / IK 미발견 32 |
| 대표 3송이의 joint seed 0/6/8 | 9 | 2 | 자체 충돌 7 |
| 원래 통과가 없던 31송이, 두 레일 위치 × joint seed 0/6/8 | 183 | 26 | 자체 충돌 120 / IK 미발견 37 |

마지막 확장은 좋은 장면만 추려서 다시 만들지 않았다. 원래 통과가 없던 31송이를 모두 포함했다. 레일 한계에 의해 같은 위치가 된 한 송이의 중복 3질의만 생성 단계에서 제외했다. 120개 차단 중 119개는 준비 연결에서, 1개는 진입에서 차단됐다. 26개는 목표의 세 자세가 모두 자체 충돌 없이 가능해도 준비 연결이 막혔다. 따라서 준비 경로 실패를 목표 자세 자체의 불가능으로 해석하지 않는다.

원본 283회 실행 결과는 모두 보존했다. 동일 타깃·위치·준비 연결·IK seed·초기 중심의 반복 9회는 다음 실행 목록에서만 중복 제거했다. 서로 다른 274개 제안 중 47개가 전체 검사에 통과했으며, 통과 제안이 있는 송이는 15개에서 **27개**, 식물은 12개에서 **18개**로 늘었다. 남은 19송이는 이 제한된 탐색에서 경로를 찾지 못한 상태다.

새 결과 파일은 공유 폴더 `20261011_013045_row_harvest_recovery` 아래에 있다.

- `row_station_screen_v6_all31_union/report.json`: 기존 실행기와 호환되는 통합 결과. 실제 선택한 connector/seed와 원본 계획 경로를 보존한다.
- `next_row_selection_all31_variants.json`: 원본 보고서·계획 SHA를 검증하는 다음 제안 목록. 최신 유효한 실제 checkpoint에서 다시 계획·환경 검사해야 한다.
- `row_all31_preparation_variants_sources/` 및 `row_all31_preparation_variants_launch_provenance.json`: 실행 시 코드 사본과 입력 해시.
- [작은 검증 요약](validation/row_all31_preparation_variants_20261011.json): 커밋 가능한 수치와 자산 해시.

기존 `run_row_harvest.select_preferred_stations`로 18식물의 제안과 각 seed 인자가 유지되는 것을 확인했다. 해당 검사는 환경 장애물, 새 식물의 초기 물리 안정성, 실제 레일 이동 및 수확 성공을 보증하지 않는다. Plant19/21/25의 별도 초기 물리 실패와 Plant40의 실제 잎·거터 와이어 겹침은 별도로 남겼다. `training_eligible=false`, `harvest_success=null`을 유지하며 기존 학습 데이터에 섞지 않는다.
