# 마지막 Fruit10: 실제 닫힘 분석과 후반 좌우 이동

독립된 새 정상 시작 실험은 418초까지 실행하여 10개 중 9개가 실제 native 꼭지 조인트에서 분리됐다. Fruit10은 남았다. 기존 화면에 표시된 약 977mm 변위는 이미 분리된 원래 manifest 타깃 Fruit11 값이며, 남은 Fruit10 값이 아니다.

저장된 전체 상태 배열은 한 번 읽고, 약 1690MB의 4,107,697개 접촉점을 한 번 순회하여 첫 마지막-열매 시도와 최종 시도를 같은 방식으로 분석했다.

|---|---:|---:|---:|---:|---:|---:|
| 3 | 158–210s | 30.95mm | 33.78° | 31.144mm | 0N | 0 |
| 7 | 366–418s | 31.05mm | 33.83° | 31.144mm | 0N | 0 |

28mm 닫힘을 명령했지만 실제 폭은 약 31.14mm에 머물렀다. 우측 벨트는 남아 있는 11번 꼭지 가지에 최대 약 2.105N의 점접촉력을 가했다. 좌측 벨트는 Fruit10과 그 꼭지 가지에 접촉했다. 우측 벨트와 Fruit10의 callback 기록은 있지만 모두 힘이 0이므로 양쪽 벨트가 실제로 잡아 돌렸다고 볼 수 없다. 첫 시도의 닫힘 마지막에는 우측 벨트 안쪽과 Fruit10 충돌 형상 사이에 약 0.456mm의 양수 간격이 남았다.

이 값들은 실제 저장 pose와 callback 기반이다. 점접촉력이나 재구성한 외력 모멘트를 PhysX 조인트 반력 또는 새로운 분리 기준으로 사용하지 않았다. 실제 조인트 반력은 이 기록에 없다. 분리되지 않은 결과를 수확 불가능으로 분류하지 않는다.

다음 보조 동작은 마지막 열매가 정확한 native 조인트 기준으로 하나만 남을 때만 적용한다. 기존 닫힘 및 재닫힘 6초의 후반에서 로봇을 CAD X 방향 ±1.5mm 이동한 뒤 같은 자세로 돌아온다. 기존 smoothstep 좌표의 앞 75%는 원래 관절 명령을 그대로 유지한다. 양수/음수 최대 이동은 각각 명령 폭 40.75/32.25mm 부근이다. 닫힘 폭·벨트 속도·전체 시간·yaw/pitch·열매 자세·물성·분리 임계값은 유지한다.

새 helper의 기본값은 비활성이다. 단위 및 기존 명령 회귀검사 24개를 통과했다. 실제 composed 로봇 FK 120Hz 검사에서는 ±1.498mm 이동, 자세 오차 7.1e-8rad 이하, 최대 관절 속도 상한 0.08792rad/s를 확인했다. 기존 2mm 자기충돌 간격을 유지한 전체 명목 경로 검사 6260개 표본도 통과했다. 이것은 경로/FK 검증이며 실제 추종과 열매 분리 성공은 아직 검증하지 않았다.

원자료는 `20261011_013045_row_harvest_recovery/trials_fresh_truss02_known9_last_lower85_depth80/fresh_truss02_known9_last_lower85_depth80_cpu16/whole_truss_last_fruit10_cycle003_capture_review.json` 및 `...cycle007_capture_review.json`에 보존했다. 후반 이동의 새 증거는 `last_fruit_sway_late_actual_plan_cpu`에 별도로 저장했고, 이전 전체 구간 sine 증거는 보존했다. 소규모 저장소 증거는 `validation/fruit10_fresh_lower80_late_sway_20261011.json`과 `validation/last_fruit_grasp_sway_late_20261011.json`에 있다. 이 진단은 학습 데이터에 넣지 않는다.

## 실제 후속 실행

위 정상 실행의 실제 최종 418초 checkpoint를 이어 후반 이동을 한 번 실행했다. 초기 상태 검증·54초 동작 완주·실제 저장 상태의 자기충돌 검사가 모두 통과했다. 추가 native 분리는 0개여서 결과는 여전히 9/10이다.

실제 이동 범위는 닫힘에서 −1.468~+1.463mm, 재닫힘에서 −1.494~+1.437mm였다. 기존 고정 자세의 오차를 분리한 최대 추종 오차는 약 0.317mm다. 명령만 달라지고 로봇이 움직이지 않은 경우가 아니다. 그러나 우측 벨트→Fruit10의 힘은 두 닫힘과 마지막 벨트 구간 모두 0N이며, 양측 유효 힘 접촉 timestep도 0이었다. 실제 닫힘은 다시 약 31.14mm에 머물렀다. 우측의 11번 꼭지 가지 접촉은 최대 2.079N, 좌측의 10번 꼭지 가지 접촉은 1.845N이었다. Fruit10 최대 변위 31.06mm, 상대 회전 35.68°를 확인했다. 실제 조인트 반력은 계속 미측정이다.

원자료 보고서는 `trials_native_fruit10_late_sway15_same_ready/native_fruit10_late_sway15_same_ready_cpu16/final_fruit10_late_sway_actual_capture_review.json`, 저장소 소규모 증거는 `validation/fruit10_native_late_sway_20261011.json`에 있다. 기존 CPU 경로 검사 결과는 이전 시점의 증거로 그대로 보존한다. 영상을 실제 물리 성공으로 해석하거나 반복 실패를 절대 수확 불가능으로 분류하지 않는다.

새 정상 시작의 실제 상태 영상 두 개도 생성했다. `fresh_native9_first_three_cycles_top_cutaway_4x.mp4`는 0~158초의 첫 9개 분리, `fresh_fruit10_last_failed_cycle_top_cutaway_2x.mp4`는 376~402초의 마지막 실패 구간이다. 같은 top camera를 사용하며, 전자는 4배속 633프레임, 후자는 2배속 105프레임이다. 전체 디코딩과 원자료 SHA 불변 검사를 통과했다. 영상의 주변 식물·잎 숨김은 재생 표시만 변경하며 자막에 표시된다. 물리를 새로 실행하지 않았다.
