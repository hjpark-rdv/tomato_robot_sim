# 열매–꼭지 탄성 연결 시험

2026-10-10. 기준 브랜치 `codex/s300-harvest-isaac-20261009`, 기준 커밋 `76479ee`.
같은 수확 동작에서 연결 방식과 파단 토크를 따로 비교했다. 탄성 연결은 실제
열매–꼭지 상대회전을 허용했고, 낮춘 파단 토크와60Hz에서 벨트 단계 분리1개 및
후퇴까지 확보했다. 그러나120Hz에서는 닫기 중 조기 파단과 겹침 중단이 발생했다.
**개선 가능성은 확인했지만, 아직 시간 간격에 안정적인 검증 모델은 아니다.**
실물 토마토의 강성·파단 특성을 측정한 모델은 아니다.

## 결과

동일 장면/동일 접근6회다. 서로 다른 토마토6개에 대한 일반화 시험은 아니다.
모든 조건에서 힘 한계3N과 기존 접촉 판정 범위를 유지했다.

분리한 열매 수는 native 연결부 파단 수다. 중단된 실행의 파단을 유효한 완료 수확으로
세지 않는다. 포집은 구현하지 않았고, 과실이 떨어지는 것이 관찰된 결과다.

- 연결 방식만 바꾼0.08Nm 조건: 11번의 꼭지 대비 비틀림 최대1.165° → 46.351°.
  분리0이므로 탄성화만으로 수확 완료라고 해석하지 않는다.
- 탄성/0.008Nm/60Hz: 10번이19.283333초(`belt_spin`)에 native 파단됐다.
  바로 전 물리 표본의 비틀림22.110°/굽힘27.915°였다. 순수 제자리 비틀림만 있었던
  것은 아니다. 이후11.217초를 더 실행하고 개방·후퇴했다. 11번은 분리되지 않았다.
- 벨트 정지 대조군: 팔·jaw 명령/단계/시간이 정확히 같고,17.5초 벨트 시작까지
  실제 로봇/식물 pose도 bit-exact다. 실제 벨트 속도0을 확인했다. 벨트를 켠 경우는
  기존 입력 조합에 따라 왼쪽 최대−0.10m/s/오른쪽0이다. 양쪽 반대 회전 시험으로
  잘못 설명하지 않는다. 벨트 off의10번 비틀림 최대12.73°/굽힘19.46°(벨트 구간), 분리0.
- 120Hz는 TGS64/4를 그대로 유지하고 시간 간격만 절반으로 줄였다.
  8번16.333333초/10번16.383333초에 닫기 중 파단,19.85초 개방 중 왼쪽벨트–8번
  1.098994mm 겹침으로 중단했다. 허용치를 올려 통과시키지 않았다.
- 60Hz 분리 실행의0.956737mm 최대 겹침은 왼쪽 상판–8번이다.
  분리한10번의 그리퍼 접촉 최대 겹침은0.467045mm, 단일 접촉점 최대힘2.43965N.
  이 힘은 조인트 반력/총합력과 다르므로3N 파단 원인을 추론하는 데 그대로 쓰지 않는다.
- 초기2.5초의 전체 과실 최대 이동은 고정0.094mm/탄성1.248mm였다.
  탄성화로 초기 하중 응답도 달라진다. 큰 발산·초기 파단은 없었다.

60Hz의 탄성화 처리 시간은 약37~39초/30.5sim초(0.79~0.81배속)였다.
단회 측정이며 GUI·병렬 환경을 이번 설정에서 새로 검증한 것은 아니다.
앱/장면 준비, 계획 검사, 저장 후 자기충돌 검사, 영상 렌더는 처리 시간에서 제외했다.
새 고정 baseline 시작 부분은 작은 fixture와 잠시 겹쳤으므로 순수 성능비에는 한계가 있다.
앞선 독립 고정 baseline은38.126초였고 이번 재실행과 저장 상태가 bit-exact였다.

## 변경 범위

기존 `assembly_tread5`를 복사해 현재 송이의 열매 10개 연결만 변경했다.
원본은 고정 연결/3N/0.08Nm이다. 탄성 시험안은 병진을 잠그고 세 회전에
수동 soft limit를 사용한다. local X는 각 열매의 실제 마지막 꼭지 방향으로 잡는다.
회전 자유구간은 ±1°이고 그 밖에서 저항과 감쇠가 작용한다.
파단은 기존 native PhysX joint break이며 시간·각도에 따른 강제 분리는 없다.

`PhysxLimitAPI`에 직접 기록한 계수는 twist 0.01, swing 0.03, damping 0.00015이다.
설치 버전의 단독 하중 시험으로 회전·복원·파단을 확인했다. 이 숫자를 보정된
조직 강성으로 해석하거나 각도 단위 변환만으로 실물과 같다고 주장하지 않는다.
모터 drive는 native break 계산에 저항력이 포함되는지의 문제가 있어 사용하지 않았다.
[PhysX joint 문서](https://nvidia-omniverse.github.io/PhysX/physx/5.4.0/docs/Joints.html),
[USD soft-limit schema](https://docs.omniverse.nvidia.com/kit/docs/omni_usd_schema_physics/latest/physxschema/class_physx_schema_physx_limit_a_p_i.html).

고정/탄성 각각 파단 토크0.08Nm 및0.008Nm를 비교한다. 힘3N은 유지한다.
낮춘 토크는 별도 가설이며 기존 기본값을 교체하지 않는다.
탄성/0.008Nm의 벨트 정지 대조군도 동일한 팔·그리퍼 명령과 시간표로 실행한다.

충돌체·질량·마찰·actuator·농장 배치와 full612DOF 식물은 보존했다.
선택된 joint spec 외의 root layer 해시와 참조 sublayer 경로의 보존을 검사한다.
기존 별도5mm 벨트면 시험안을 사용하며 원래 CAD 또는 V6의 성능 검증이 아니다.
현재 송이 열매–그리퍼만1mm, 나머지 활성 접촉 및 초기 상태0.5mm의 기존 진단 기준을 유지한다.

## 검증 방법

- 기존 `benchmark_motion.py` → `run_motion.py` → `analyze_belt_trial.py`를 재사용한다.
- 60Hz/TGS64/4, CPU2threads, CCD on. 진입/닫기6초/벨트2초/개방/후퇴, 총30.5초.
- 실제 physics 주기의 qpos·바디 pose·접촉·native break event를 보존한다.
- 열매와 꼭지의 상대 자세를 twist/bend로 나눈다. 파단 후 낙하·자유회전은
  연결된 상태의 회전 통계에 합치지 않는다. 파단 스텝 표본은 별도 해석한다.
- native break event만으로 힘·굽힘 토크·비틀림 토크 중 어느 한계가 원인인지 구분할 수 없다.
- `--belt-off-control`은 실제 벨트 속도만0으로 하고 같은 팔/그리퍼 명령을 사용한다.
  두 실행의 명령/시간 및 벨트 이전 실제 상태도 비교한다.

단독 fixture는 무중력 두 강체에 알려진 torque를 가하는 구현 시험이다.
아주 작은 관성의 몸체에 토크를 직접 가하면 엔진 회전속도 제한이 파단 시험에 영향을 준다.
최종 fixture만 그 제한을 높여 회전·복원·native break를 분리 확인했다.
**농장 모델의 회전속도 제한은 바꾸지 않았다.** fixture 파단을 농장 수확으로 세지 않는다.
초기 단위 변환/기본 속도제한 비교에서 실패한 fixture와 하네스 오류도 삭제하지 않았다.
