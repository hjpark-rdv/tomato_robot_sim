테스트로 확인한 범위:
- 실제 d1 생성기를 이용한 네 경로군의 국소 변경이 준비/접근 위치·회전·시간 경유점을 바꾸지 않는지.
- 기록된 prefix 명령·phase·시간의 보존, 실제 SHA 검증, 잘못된 source/기록 거절.
- 같은 prefix 그룹 중복 제거, 서로 다른 장면·타깃 선정, 국소/접근 집단 분리.
- 측면 자기충돌을 한 대표 질의로 고정, 미평가 예산과 실패 분리.
- 기존 native 충돌·허용쌍·모델캐시·측면 입구 모드·힘 표시 회귀.
- 실제 OMPL의 단순 장애물 우회와 native MuJoCo 형상 검사.

## 입증하지 않은 것

대형 온실 MJB/planning pickle을 사용하는 새 CLI의 전체 서버 실행, 실제 RB5/FCL의 경로 통과율, 새 물리 도달·삽입·걸림 성공률, 대표 MP4는 아직 없다. 일부 실행 계약 시험은 테스트용 계획기/환경 대체 객체를 사용한다. 테스트 수를 수확 성공 건수로 해석하지 않는다.

변경 비교에서 d1 이후 추가 파일만 존재함을 확인했다. 서버의 기존 생성기·캐시·접촉/힘 정책·실행기·보고서 파일은 수정하지 않았다. 새 어댑터는 기존 함수를 호출하며 서버 연결과 성능은 다음 한 라운드에서 검증한다.
