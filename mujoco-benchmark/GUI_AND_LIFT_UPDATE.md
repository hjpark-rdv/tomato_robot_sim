# 2026-09-27 GUI 및 상승 경로 변경

`learning/test_direct_angle.py --gui`는 물리 실행 상태를 별도 MjData에 복사하여 실시간 표시한다. 준비 단계 로그 파일 경로를 터미널에 출력한다. 기존 결과/상태 저장 및 완료 HTML을 유지한다.

새 후보와 직접 예측 실행은 `diagonal_75_return`: 수평 기준75°, 전진/후퇴 각각 수평4.354mm + 상승16.25mm, 최종상승32.5mm. 기존 저장15°/45° profile은 원래 경로로 복원한다. 기하검증 완료, 새75° 물리검증 미실시.

기존45° 명령의 별도 Hz 진단: `20260927_all_targets_hz_comparison`에 동일10열매×120/240Hz 결과 저장. 진동47~89% 감소, 물리오류1→0, 중심진입9→10. 일부 밀림 증가(Tomato07 22.3→29.3mm). 단일장면이며 기본120Hz는 변경하지 않았다. 원본과120Hz 재실행 판정/변위 일치. 최초GUI 짧은 검증에서 상태 동등성 확인.
