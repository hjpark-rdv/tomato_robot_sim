## 기존 분석에서 고친 점

### 1. 접근만 고치면 되는 실험이 아니다

원래 파일럿 환경검사 차단239개를 `pilot_blockers.json`의 최초 차단 단계로 합산하면 준비105 + 접근34 = **139개**, 삽입99 + 안착1 = **100개**다. IK 미발견1개는 이239개에 넣지 않는다.

측면을 제외한 네 경로군192개에서는 공통 prefix 차단92개, 분기 이후 차단100개다. 48개 파라미터×타깃 그룹이 네 경로의 prefix를 공유하며 그중23그룹이 앞에서 막혔다. 따라서 접근 우회가 필요한 대상과, 이미 접근 구간을 통과한 국소 삽입 대상은 나누어야 한다. 단, 여기서 통과는 정적 명목 검사이며 실제 물리 도달이 아니다.

### 2. 네 경로군의 진입 자세는 이미 낮은 기울기다

`motion_family_search.make_candidate`에서 측면 이외의 `entry_r`는 이미 `orientation(h, 0., 0.)`이다. 표본의 roll/pitch는 주로 뒤쪽 국소 동작과 최종 자세를 바꾼다. 따라서 roll/pitch를 낮추자는 제안만으로 앞의 공통 prefix 충돌이 해결되지는 않는다.

이번에는 방위각·고도·준비 위치를 동시에 다시 샘플링하지 않는다. 앞부분이 막힌 경우는 같은 준비 위치/회전을 유지하며 관절 해와 경로를 바꾸고, 앞부분이 통과한 경우는 기록된 관절명령·phase·시간을 그대로 둔 채 국소 기울기만 대조한다.

### 3. 측면 자기충돌은 대표 표본으로 먼저 분리한다

측면 수정 CSV의 자기충돌12개는 모두 같은 표본 ID `mf_20260928_00003`이다. 예를 들어 scene_0003/truss_01__Tomato_04에서는 approach의 step447에서 segment08-link3가 충돌했다. 이는 12개의 독립적인 방향 모두가 실패했다는 의미가 아니다. 끝 자세의 충돌인지, 선택한 관절 해/접근 중 충돌인지는 아직 따로 검사해야 한다.

이번 라운드는 이 표본의 한 타깃을 별도 대조로 골라 같은 준비 목표에 다중 IK+경로 연결을 적용한다. 자기충돌 허용 범위는 변경하지 않는다.

## 구현 내용

- `approach_connection.py`: 이전 1be29ea의 유한 예산 OMPL/IK 핵심을 재사용한다. 새로운 알고리즘을 또 만들지 않는다.
- `plan_approach_connection.py`: 원래 prefix를 **먼저 독립적으로 재검사**한다. 유효하면 기록 명령·phase·시간·관절 해를 보존하고 OMPL을 건너뛴다. 막혔을 때만 같은 handoff 목표에 다중 IK/우회 연결을 시도한다.
- `--require-recorded-prefix`: 국소 대조군이 원래 prefix를 사용할 수 없으면 중단한다. 몰래 다른 접근으로 바꾸어 대조 실험의 의미를 없애지 않는다.
- `--local-design recorded|neutral|neutral_pitch15`: 기존 국소 파라미터, 국소 roll/pitch/twist를 모두0으로 한 대조, 그 대조에서 pitch만15도로 바꾼 경우다. 기존 생성기를 호출하며 앞부분의 경유점 일치를 검증한다. 목표 꼭지/와이어 관계를 유지하므로 최종 위치도 달라질 수 있으며, 위치 고정 회전 실험이라고 주장하지 않는다.
- `recorded`도 suffix를 도달 관절 해에서 다시 계획한다. 전체 원본 trace와 bitwise 같다는 뜻은 아니다. 정확히 보존하는 것은 앞부분 명령과 시간/phase다. 원본 suffix와 재계획 결과의 비교는 따로 남긴다.
- `prepare_recovery_batch.py`: 실제 prefix SHA를 대조하여 중복 그룹을 한 번만 선택하고 질의 목록을 고정한다. 새 장면, 대규모 Sobol, 물리 실행은 자동 생성하지 않는다.
- d1의 허용쌍 최적화, hash 검증 캐시, 측면 입구 모드, phase 별칭, 힘 집계와 보고서는 변경하지 않는다. 캐시는 기존 `search_model_cache.attach/restore`를 사용한다.
- IK 단계의 끝 자세 자기충돌과 환경 충돌 이유를 분리한다. 조건부 접근-only 출력과 전체 경로 출력도 분리한다.

질의당 기존 IK 초기값8개, 유효 관절 해 최대3개, OMPL 해당8초, 전체120초, 외부 프로세스180초를 사용한다. 배치 계획1500초로 제한한다. 시간 초과는 불가능 판정이 아니다. 실제 물리는 별도 승인된 후보에서 접근-only 포함 **최대8회**, 반복 증액하지 않는다.

## 진척 판단과 다음 분기

- 앞부분이 개선된 대상은 그 원래 국소 동작까지 연결하여 검사한다. 국소군은 접근 개선을 기다리지 않고 함께 시험한다.
- 전체 경로 통과 결과를 우선 실제 실행한다. 접근만 통과하면 제한된 도달 대조로 확인하되 수확 시도로 집계하지 않는다.
- 접촉력 한도를 올리거나 마지막1.4mm를 반드시0으로 맞추는 실험으로 돌아가지 않는다.
- 이번 한 라운드에서 준비/삽입까지 실질적 도달 증가가 없으면 같은 방식의 표본 증액을 종료한다. 유효 목표 없음, 연결 미발견, 국소 충돌, 실제 추종 문제를 구분해 보고한다.
- 접근 가능하지만 국소 동작이 여전히 병목이면, 이미 유효한 준비 상태에서 **국소 경로 최적화 대 국소 RL** 비교를 다음 실험으로 한다. 같은 장면·관측·접촉 정책·계산 예산과 고정된 평가기를 사용한다. 전체 초기 접근까지 새로 RL에 학습시키는 것으로 즉시 교체하지 않는다.
- 목표 자세 자체가 자기충돌이면 더 오래 RRT를 실행하지 말고, 준비 위치/고리 자세/로봇 배치 중 무엇을 바꿔야 하는지 한 가지 근거를 제시한다. 구조적 불가능을 유한 IK 실패만으로 확정하지 않는다.
- 여러 타깃에서 실제 국소 실행을 확보한 뒤 기존 통과4장면80열매, 그다음 독립 새 장면으로 확장한다.

기하 후보와 접촉 유지 증거는 각각 보존한다. 가까우나 접촉0인 후보를 명백한 실물 실패로 확정하지 않고, 가깝다는 이유로 수확 성공도 선언하지 않는다. 현재 충돌 모델의 정확도가1.4mm보다 좋다는 실측 근거가 없다는 점과, 오차가 반드시 그 간격을 설명한다는 증거도 없다는 점을 함께 유지한다.

## 변경하지 않는 조건과 검증 범위

목표 과실/목표 송이 Rachis의 정확한 고리 와이어 접촉 허용은 유지한다. 비목표 과실·꼭지·주줄기·거터와 팔/마운트 접촉 허용은 확대하지 않는다. 기존 물성·제어·0.5mm 수치 유효성, 5N/20mm 실험 중단값을 유지한다. 중단값은 실물 손상 한계가 아니다.

`hook_success=null`, `training_eligible=false`, `impossible=null`을 유지한다. 기존 RGB-D 입력/출력 형식이나 학생 모델은 바꾸지 않는다.

CI는 d1의 native 회귀 목록과 접근 연결기 및 새 대조 시험을 실행한다. 기능 테스트가 온실 전체 경로 통과 또는 실제 수확 성공을 입증하지는 않는다. 대형 MJB와 Torch/FCL이 필요한 전체 서버 통합은 다음 인수인계 실행 범위다.
