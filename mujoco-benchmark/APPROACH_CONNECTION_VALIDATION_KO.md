## 이번 변경이 해결하려는 범위

기존 준비/접근 구간이 단순 보간에서 막힐 때, 같은 목표 자세로 다른 관절 자세와 경로를 찾는다. 고리 tip만이 아니라 기존 FCL 자기충돌과 MuJoCo의 로봇 전체/환경 형상을 검색 중 검사한다. 실제로 도달한 IK branch에서 원래 국소 경로를 다시 계획한다.

prefix 발견, 전체 경로 통과, 실제 접근 도달, 실제 고리걸림은 별개다. 독립적으로 검사한 approach_only_run을 남기지만 이는 준비 자세 접근 시험이며 manipulation_attempt=false다. 실제 실행 시 이 결과를 수확 성공으로 집계하지 않는다.

- 최신 서버 브랜치의 실제 코드 변경과 원자료.

- 이번 경로로 수확 성공률 또는 실물 성능이 개선되는지.

도구는 별도 실험용이며 물리 실행을 자동 시작하지 않는다. 0.5mm 유효성, 기존 물성, 접촉 정책과 힘/변위 한계를 바꾼 것이 아니다. OMPL 검사도 이산 정적 기하 검사이며 연속 충돌 안전성이나 동역학 성공을 보장하지 않는다.
