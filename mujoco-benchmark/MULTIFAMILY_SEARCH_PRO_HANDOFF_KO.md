## 수정과 해석의 한계

서버 연결 수정은 환경 검사 허용쌍 조회 최적화, 해시 검증 MJB 캐시, 실제 허용 힘 표시, azimuth 비교용 phase 별칭, 읽기 전용 집계/FK 검증이다. 기존 실행기·IK/FCL·물리는 재사용했다. 물성·충돌체·margin/gap·마찰·강성·actuator·0.5mm 기준을 바꾸지 않았다. 5N/20mm는 실험 중단값이며 실물 안전 한계가 아니다.

새6장면은 기존 생성기의 하우스/거터/주줄기+2송이이며 주변106송이 밀집 환경 전체를 복제한 것은 아니다. 밀집 환경은 기존 gutter02 대조군에서 확인했다. 새 경로5종 모두 실제 실행까지 통과하는 완료 조건은 아직 충족하지 못했다. 실패 경로를 물리에 강제로 넣지 않았고, 수확 불가능으로 단정하지 않았다. `training_eligible=false`, `hook_success=null`, `impossible=null`이다.
